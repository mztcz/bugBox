bugBox Breeding Sim

Start: T1 bugs from the Market. Each mating pairs the two unmated bugs with the highest Pwr (stat sum). The child is unmated and can mate in the same round.

A round ends after the set number of matings, or when fewer than 2 unmated bugs remain. Then all bugs can mate again.

Can mate after N rounds: a child born in round R can mate from round R + N. 0 = already in the round it is born.

Box full: mating goes on, and for every new child the weakest bug (lowest Pwr, never the new child) is removed.

m+ = 1 mating. s+ = finish the round (all its matings; if the round is over, run the whole next round). s+10 = 10 whole rounds. ▶ / ■ = start / stop automatic matings at the chosen speed.

G = generation counted along the longest line of ancestors (max of parents + 1). g = counted along the shortest line (min of parents + 1). G1 × G7 → G8 (g2).

All 4 methods run in parallel from the same start bugs. Cards, log and table show the selected method. Abilities follow the game rules (lab.js v74.63) in every method.

Family tree of the selected method. The Tree checkbox opens it full screen; ← Back returns. Scroll in both directions, zoom with − / + / Fit or pinch. m+, s+, s+10 and ▶ work here too.

View: rows = one row per round (inside a round one row per G, lower G above), or per G, g, Pwr; align: left = child one card to the right of its left parent, center = one parent (the younger one) in the middle and the child mirrored on the other side of it from the other parent, so both parents and the child are evenly spaced; if that place is taken or more than one card beyond the widest card so far, the other parent becomes the middle one, then the child goes to the middle between its parents, Right = child to the right of its right parent, Crown = each row centred on one common axis and ordered by where the parents stand (a balanced crown), Mid = each child right under the middle point between its parents, a taken place goes to the nearest free one alternately right and left. uncrossed = the same rows reordered so fewer lines cross. ancestors = only the last tapped bug (or the best one) and its ancestors, each bug once, one bug per row by number (lower number always higher), root at the bottom. chain = each round as one line of its children; the line between neighbours is the round's mating chain, dotted small boxes above a child = copies of its other parent(s).
